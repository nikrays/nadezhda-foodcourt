# Фудкорт «Надежда» — 3D

Интерактивная 3D-сцена летнего фудкорта санатория «Надежда» (Анапа): линия раздачи по плану, гриль, мангал, казан, паэлья, вертел, ракурсы и фото-рендеры.

Открыть: страница `index.html` (GitHub Pages).

Ресурсы: three.js (MIT), панорамы неба Poly Haven (CC0), текстура травы из примеров three.js (MIT).
